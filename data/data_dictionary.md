# Data Dictionary

Synthetic dataset created specifically for this project; it is not from a real company.

- `ticket_id`: historical ticket identifier
- `ticket_text`: unstructured IT support request
- `category`: high-level issue domain
- `issue_type`: specific issue type
- `priority`: project-defined urgency class
- `assigned_team`: historical routing label
- `sentiment`: simple support-oriented sentiment signal
- `resolution`: historical resolution/action text

Priority labels are project-defined demonstration labels, not real enterprise SLA commitments.
